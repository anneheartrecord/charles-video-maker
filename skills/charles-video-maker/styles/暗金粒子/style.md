# 风格配方卡：暗金粒子

蒸馏自：许先森Ai 全部 10 条作品（2026-10-26 拆，四条爆款 1.1 万～11.7 万赞），拆解要点见 `references/douyin-opening.md` 的对标二。首次使用：平均人开头 14.6 秒样片；之后 10-28 的排老几、几岁最自信、最孤独、最能熬夜、最聪明五条都用它。

- **画幅**：横屏 1920×1080 / 30fps。原作者无配音，只用配乐和字幕；我们默认照常配音，无配音版只在对比时做。

- **底色**：近黑 `#020203`，四周压暗角；远处撒几百颗暗金尘点慢慢转，画面永远不是纯黑。

- **主色**：一个暖金（粒子 `rgb(255,158,51)` 一档，字用金色渐变 `#ffe7a8 → #f2b44a → #b9771f` 加辉光）；出事、警告整团粒子转红 `rgb(255,56,31)`；线框用暖白 `#fff1d6`。不加第三种颜色。

- **主体**：全部用发光粒子拼出来。在 2D 画布上画一个实心剪影，采样 4063 个点（轮廓占一半、填充占一半），每个点是加色混合的柔光点，中心一粒亮芯。适合物体、动物、器官、地球、交通工具、问号这类字形；人物只做剪影或手，不做脸。

- **空间**：白色细线框搭出来（盒子、驾驶舱、地平线、测量线），透明度 0.25～0.9，不填面。

- **运动（招牌）**：一个粒子集合贯穿全片，场景之间不切镜头，而是所有点散开再聚成下一个形状。每个点有自己的延迟（最多 0.35 秒），路上带一点随机漂移，用时约 1 秒。镜头一直在慢推或轻微环绕，从不完全停下；每个点有微小的呼吸抖动和亮度闪烁。

- **字**：
  - 字幕在底部居中，PingFang 600、44px、白字，关键词金色，不加底框，只加黑色投影；
  - 大数字和概念名用宋体（Songti SC 900）金色渐变，比如开头的 4063 和平均人；
  - 左上角章节标签用宋体 26px 金字，下面一行 15px 暗金小字写出处或年份；
  - 列表放主体旁边，序号用宋体金字，跟着测量线逐条进场。

- **开头**：按 douyin-opening.md 的开头 5 秒四拍来做。
  - 第 0 帧就是完整画面：4063 个光点排成方阵，宋体金字 4063 已经在上面，方阵后面立着一个白色虚线的标准人，一开场就有错位；
  - 第一句旁白和数字同时出现；
  - 1.6 秒时所有光点飞起来，聚成一个人；
  - 反转那一拍：光点退回方阵后成排熄灭，金字数字一路往下掉；接着收暗 0.2 秒、定 3 帧，砸出大号问号并配一圈冲击波。熄灭的光点在下一个场景里边飞边亮起来，不一下全亮。

- **画面跟字幕**：每条字幕出来时画面都有一件事发生，可以是变形、测量线进场、对勾弹出、整团转红、镜头推进或扫描线扫过。渲完跑 `still_check.py`，样片为 0 段静止。

- **技术**：Three.js 0.160 打成 IIFE（本目录的 `three.iife.js`，重新打包方法见 `styles/README.md`），`THREE.Points` 加自写 ShaderMaterial 做辉光，`preserveDrawingBuffer: true`，每帧 `gl.finish()`。所有位置都由 t 和带种子的随机数算出来，帧与帧之间不存状态。叠在画布上的文字和对勾用 DOM 画，位置用 `Vector3.project(camera)` 换算。4 进程并行渲染 14.6 秒用时 17 秒。

- **没有搬的东西**：原片的字幕稿、选题、配乐、人物照片；粒子造型和版式参数全部重新写。
