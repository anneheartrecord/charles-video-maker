# 风格配方卡：霓虹血条风

蒸馏自：#Vibe知识大赏「为什么一句狠话，要五次温柔才能抵消？」（Apodfg，2026-10-19，51s）。首次使用：five-kindness（2026-10-20）。

- **画幅**：横版 1920×1080 / 30fps，一镜到底为主，场景之间 0.3s 叠化，高潮硬切。
- **配色**：纯黑底 #050508；主色霓虹粉 #ff5c93（深 #c2185b）；伤害红 #ff3b4a；回血绿 #5cffb0；高潮金 #ffd166；正文白 #f4f4f7；注释灰 #8b8b99。
- **字体**：PingFang SC 800–900 粗黑；关键词按语义上色（坏事红、温柔绿、结论金）并带同色外发光；数字一律自绘 5×7 像素点阵。
- **招牌画面**：立体高光爱心（液面高度 = 血量，受伤出黑色裂纹）；10 颗像素心「感情值」血条；游戏 HUD 道具卡（图标 + 名称 + 「生命恢复 +10」）；浮起的像素伤害/回血数字；GAME OVER 像素字；发光折线历史图。
- **版式**：顶部常驻标题条（粉色竖条 + 白字 + 关键词上色）；主字幕底部居中 58–72px，一屏一句；出处小字右下灰色。
- **动效**：卡片、字幕用弹簧（w 15–22）；伤害 = 0.5s 衰减震屏 + 0.12s 红闪 + 像素碎片；高潮 = 提前 0.75s 收暗、末 3 帧静止、重拍砸字（1.6→1 沉弹簧）+ 冲击波圆环 + 粒子。
- **质感**：径向暗角 + 每秒 24 次变化的细颗粒。
- **配乐**：100 BPM，拇指琴游戏音开场 → 立式钢琴 + 马林巴 + 拨弦低音 + 踩镲拍手律动；回血用上行钟琴音；高潮前弦乐震音渐强。全部 CC0 采样 + 代码合成鼓。
- **没有搬的东西**：原片的字幕句子、道具卡文案、配乐、作者名、水印；原片「吵完之后补回来」的错误说法。
